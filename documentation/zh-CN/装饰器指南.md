# NarrativeTrace TypeScript 装饰器指南

[English](../decorators-guide.md) | [Español](../es/guia-de-decoradores.md) | [Português](../pt-BR/guia-de-decoradores.md) | **简体中文**

本指南列出 NarrativeTrace TypeScript 中可用的全部装饰器,并说明每个装饰器的使用时机与使用方式。

NarrativeTrace 遵循**代码即日志**的理念:方法名、参数名和返回值本身就应当讲清运行时的故事。请首先保持业务逻辑干净、富有表达力,装饰器只在例外情况下使用,而不是默认使用。只有当装饰器能带来具体的额外价值时才添加,例如有针对性的叙述文本、面向特定错误的上下文,或敏感数据脱敏。

## 装饰器一览

| 装饰器 | 模块 | 作用目标 | 用途 |
|---|---|---|---|
| `@traced()` | `@narrativetrace/proxy` | 方法 | 为追踪输出绑定参数名。 |
| `@narrated()` | `@narrativetrace/proxy` | 方法 | 为被追踪的方法添加人类可读的叙述文本。 |
| `@onError()` | `@narrativetrace/proxy` | 方法 | 在方法抛出异常时添加上下文相关的错误文本。 |
| `@notTraced()` | `@narrativetrace/proxy` | 方法 | 将参数值标记为在追踪输出中脱敏。 |

所有装饰器都使用 [TC39 Stage 3 装饰器提案](https://github.com/tc39/proposal-decorators)(TypeScript 5.0+)。它们是使用 `ClassMethodDecoratorContext` 的方法装饰器。

## `@traced`

使用 `@traced` 绑定显式的参数名。当压缩工具(minifier)会剥离参数名,或者你希望在追踪中使用更具描述性的名称时,这一点至关重要。

```ts
import { traced } from "@narrativetrace/proxy";

class OrderService {
  @traced("customerId", "productId", "quantity")
  placeOrder(cId: string, pId: string, qty: number) {
    // ...
  }
}
```

工作原理:

- 参数名存储在一个以方法函数为键的 `WeakMap` 中。
- 当 `traceObject()` 拦截一次调用时,会查找这些名称,并用它们代替 `arg0`、`arg1` 等。
- 名称是按位置对应的——它们通过索引与参数建立映射。

### 不使用 `@traced`(手动指定参数名)

如果你无法使用装饰器,或者不想使用,可以直接将参数名传给 `traceObject()`:

```ts
const traced = traceObject(orderService, context, {
  placeOrder: ["customerId", "productId", "quantity"],
  cancelOrder: ["orderId"],
});
```

这等价于 `@traced`,但无需任何装饰器支持即可运行。

## `@narrated`

当你希望追踪中出现一句明确的句子,而不是只依赖方法名加参数时,在方法上使用 `@narrated`。

```ts
import { narrated } from "@narrativetrace/proxy";

class OrderService {
  @narrated("Placing order of {quantity} units for customer {customerId}")
  placeOrder(customerId: string, quantity: number) {
    // ...
  }
}
```

工作原理:

- 叙述模板存储在一个以方法函数为键的 `WeakMap` 中。
- 该模板字符串会附加到追踪节点的 `MethodSignature.narration` 字段上。
- 与 `traceObject()` 配合使用——叙述文本会以斜体形式出现在 Markdown 输出中调用记录的下方。

占位符的解析方式:`{paramName}` 会替换为对应名称的参数;`{param.property}` 会在原始参数对象上调用相应的 getter。只会解析单个属性层级——`{order.card.number}` 永远不会被解析,占位符会原样保留。通过属性路径抵达的被脱敏成员,解析结果为 `[REDACTED]`,而不是原始值——参见下文 `@notTraced` 部分的脱敏说明。

## `@onError`

使用 `@onError` 为异常附加特定于上下文的消息。

```ts
import { onError } from "@narrativetrace/proxy";

class PaymentService {
  @onError("Payment declined for customer {customerId}, amount was {amount}")
  charge(customerId: string, amount: number) {
    // ...
  }
}
```

工作原理:

- 错误上下文模板存储在一个以方法函数为键的 `WeakMap` 中。
- 当方法抛出异常时,错误上下文会附加到追踪节点的 `MethodSignature.errorContext` 字段上。
- 在异常消息之外,为错误追踪补充特定于业务领域的上下文信息。

## `@notTraced`

使用 `@notTraced` 对敏感的参数值进行脱敏。

```ts
import { notTraced } from "@narrativetrace/proxy";

class AuthService {
  @notTraced(1) // 对索引为 1 的参数进行脱敏
  login(username: string, password: string) {
    // ...
  }
}
```

工作原理:

- 参数索引存储在一个 `WeakMap<Function, Set<number>>` 中。
- Proxy 会在追踪输出中将被脱敏的参数渲染为 `[REDACTED]`。
- 对于被脱敏的参数,`ParameterCapture.redacted` 会被设为 `true`。
- 可以同时脱敏多个索引:`@notTraced(1, 2)`。
- 对于**对象字段**,声明一个静态类字段:`static notTraced = ["pan", "secret"]`
  ——这些属性会在内省期间渲染为 `[REDACTED]`,与基于名称的 `RedactionPolicy` 拒绝列表
  (该列表已覆盖 `password`、`token`、`ssn`、`cvv` 等)相互独立。
- 典型用例:密码、token、机密、卡片数据。

**脱敏优先于点名它的模板。**`@narrated` 与 `@onError` 会在原始参数上解析
`{param.property}` 路径,而抵达被脱敏成员的路径解析结果为 `[REDACTED]`——无论该成员是被
基于名称的拒绝列表覆盖,还是被显式列在 `static notTraced` 中。点名一条路径,绝不会削弱
直接作用于该值的规则:

```ts
class Card {
  static readonly notTraced = ["cvv"];
  constructor(readonly last4: string, readonly cvv: string) {}
}

class PaymentService {
  @narrated("Charging card ending {card.last4}, cvv {card.cvv}")
  @traced("card")
  charge(card: Card) { /* ... */ }
}
// narration: "Charging card ending 4111, cvv [REDACTED]"
```

如果你确实需要在叙述中呈现该值,请将其从 `static notTraced` 中移除(或从其匹配的拒绝列表
模式中移除)——这一移除动作才是刻意做出、可供评审的决定。占位符点名了对象上不存在的属性,
这是书写上的笔误,而不是脱敏决定:它会原样保留,并且测试期间的未解析占位符警告仍然会为它
触发。

## 纯净性契约——追踪期间的副作用

NarrativeTrace 在渲染追踪时,可能会调用你的对象上一小组固定的代码路径。请保持这些成员
**纯净**——不含懒加载、访问计数器、缓存填充或 I/O 等副作用——就像面对调试器或序列化器时
那样。

哪些会被调用,哪些不会:

- **内省会枚举自身可枚举属性**(`Object.keys`)。定义在类上的 getter 存在于原型上,
  永远不会被枚举,因此也永远不会在内省期间运行。(直接定义在对象字面量上的访问器*确实*是
  自身可枚举的,会被运行——请优先使用类 getter,或者在 `static notTraced` 中标记该字段。)
- **NarrativeTrace 确实会调用的是:** 自定义的 `toString()`(自身定义,非默认实现)、被
  `@narrativeSummary` 指定的方法,以及你在 `@narrated`/`@onError` 模板中点名的任何属性
  路径——`{order.total}` 通过属性访问来解析,因此被点名的 getter *会*运行。
- **调用是有界且隔离的。** 输出有上限(`maxStringLength`、`maxArrayItems`、
  `maxObjectKeys`);抛出异常的 getter 或 `toString()` 永远不会导致被追踪的业务调用失败
  (模板会回退为字面量 `{placeholder}`,渲染会回退为类型名标记);值会在调用点被立即
  (eager)渲染,因此任何副作用只发生一次,发生在确定的时间点。Thenable 对象永远不会被
  等待(await)——它们会渲染为 `<pending>`。

如果某个成员无法保持纯净,就把它列入 `static notTraced`——被脱敏成员的值根本不会被读取
——或者为该类型提供精心编写的 `toString()`/`@narrativeSummary`,由你精确控制会访问到什么。
当上下文处于非激活状态时(级别为 `off`,或在 `summary` 级别下参数捕获被禁用),完全不会
进行任何参数渲染——快路径上不会触碰任何用户代码。

## 组合使用装饰器

装饰器可以在同一个方法上叠加使用:

```ts
import { traced, narrated, onError, notTraced } from "@narrativetrace/proxy";

class TransferService {
  @traced("fromAccountId", "toAccountId", "amount", "authToken")
  @narrated("Transferring {amount} from {fromAccountId} to {toAccountId}")
  @onError("Transfer rejected for source account {fromAccountId}")
  @notTraced(3) // 对 authToken 进行脱敏
  transfer(from: string, to: string, amount: number, token: string) {
    // ...
  }
}
```

这一个方法就组合了参数命名、叙述、有针对性的错误上下文,以及参数脱敏。

## 完整示例

```ts
import { NarrativeTraceConfig, SyncNarrativeContext, renderMarkdown } from "@narrativetrace/core";
import { traceObject, traced, narrated, onError, notTraced } from "@narrativetrace/proxy";

class PaymentService {
  @traced("customerId", "amount", "token")
  @narrated("Charging {amount} to customer {customerId}")
  @onError("Payment failed for customer {customerId}")
  @notTraced(2) // 对 token 进行脱敏
  charge(customerId: string, amount: number, token: string) {
    if (amount > 1000) throw new Error("Amount exceeds limit");
    return { transactionId: "TX-1", amount };
  }
}

const config = new NarrativeTraceConfig();
const context = new SyncNarrativeContext(config);
const traced = traceObject(new PaymentService(), context);

traced.charge("C1", 500, "tok_secret_123");
console.log(renderMarkdown(context.captureTrace()));
```

# 搭配你的智能体使用 NarrativeTrace

[English](../use-with-your-agent.md) | [Español](../es/usa-narrativetrace-con-tu-agente.md) | [Português](../pt-BR/use-narrativetrace-com-seu-agente.md) | **简体中文**

NarrativeTrace 以开放的 Agent Skills 格式提供[智能体技能](智能体技能.md)——智能体用来安装本库、阅读追踪并诊断安装情况的一套流程。下表中的每个平台都能自动发现 `init` 写入 `.agents/skills` 的页面,所以只有一套页面,没有按平台区分的副本。各平台之间的差别在于:外部使用者如何把这些页面放进项目,以及哪个小文件会在智能体想起去找之前就先把它指向这些页面。

## 平台一览

## `init` 写入的指针文件

指针是平台本来就最先读取的一个小文件。只有当项目表明该平台在使用时才会写入,绝不是技能页面的副本,也绝不通过符号链接:

- **Cursor**——`.cursor/rules/narrativetrace.mdc`,一条始终生效的规则,说明技能在哪里,仅当项目有 `.cursor/` 目录时才写入。Cursor 插件附带同一条规则。
- **Replit**——`replit.md` 中带标记的 NarrativeTrace 小节,即 Replit 智能体最先读取的项目记忆,仅当项目有 `replit.md` 或 `.replit` 时才写入。它与 `AGENTS.md` 所带的小节相同,标记也相同。
- **Antigravity、GitHub Copilot、Claude Code**——没有指针。它们直接读取 `.agents/skills` 和 `AGENTS.md`(Antigravity 将 `AGENTS.md` 作为规则加载;Claude Code 还会读取 `.claude/skills`,`init` 会在每个项目中写入它)。

如果某个指针与 `init` 将要写入的内容完全相同,就会被接管而不是被拒绝;不属于我们的文件在没有 `--force` 时会被拒绝;`npx @narrativetrace/cli uninstall` 只会移除它自己写入的指针。`npx @narrativetrace/cli doctor` 会报告每个检测到的平台的指针是否存在且为最新,或者指出缺失、过期或不属于我们的是什么。

## 手动复制

复制适用于任何平台,也是没有自身构建环境的智能体唯一可走的路径:

- **Codex**:目录会在同一文件夹中渲染出 [`.agents/skills/narrativetrace-doctor/`](../../.agents/skills/narrativetrace-doctor/SKILL.md) 以及其他技能目录——这是 Codex CLI 为项目自有技能记录的、签入仓库的布局,它会自行发现,从工作目录一路向上找到仓库根目录(此外还会查看 `~/.agents/skills` 里的用户级全局技能)。其 frontmatter 只有 `name` 和 `description`(Codex 的文档中没有 `when_to_use` 或 `allowed-tools` 键);页面正文其余部分完全相同。把相应目录复制到你自己项目的 `.agents/skills/<名称>/` 下,Codex 就会以同样的方式发现它。来源:developers.openai.com/codex/skills 和 developers.openai.com/codex/concepts/customization(获取于 2026-09-13)。
- **Antigravity**:工作区技能从 `.agents/skills/`(旧版为 `.agent/skills/`)读取,所以同样的复制方式在 IDE 和 `agy` CLI 中都有效。它的插件安装器只读取插件顶层的 `skills/` 目录,而本仓库不提供该目录,因此没有 `agy plugin install` 这条路径。
- **任意智能体、任意平台**:任何会读取 `AGENTS.md` 的智能体都能看到 `init` 写入其中的常驻小节——技能的名字和描述,这样一个从未想过要去找它们的智能体也能知道它们的存在。

## 依据

每个平台那一行都注明了支撑它的试用。Claude、Codex、Antigravity 和 Cursor 通道会针对一个示例项目,用安装提示词驱动真实的命令行智能体;如果某个通道的 CLI 没有安装,它会用一行提示跳过而不是失败;Replit 和 GitHub Copilot 则是由所有者记录的手动试用。各通道、零星配额策略和晋级矩阵见 [Tier B——LLM 试验](../../packages/skills-catalogue/evals/README.md)。
